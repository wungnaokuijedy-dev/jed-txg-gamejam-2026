# Where Nature Leads

> *The forest doesn't tell you where to go. It shows you.*

An atmospheric 10-12 minute exploration game about listening to a forest — nurturing what is fading, restoring what has been broken, and choosing what to do when you find the thing at the heart of it. Built as a single-page WebGL game that runs entirely in the browser: no server, no accounts, no downloads.

Submitted to **TXG Nagaland Game Jam 2026**.

---

## Theme integration — *Where Nature Leads*

Every mechanic in the game is nature guiding the player instead of the player commanding nature:

- **Forest Health** is a hidden variable that rises when you nurture (plant seeds, restore the spring, free a tangled bird, awaken stones) and falls when you take from the world (harvest glowing flowers, pluck a mushroom ring, and — as the final act — take the Heartseed). It quietly drives lighting, fog, ambience density, and the ending.
- **Navigation** is never a HUD arrow. Butterflies drift toward the next seed. Fireflies gather to lead you into the Grove. A deer looks back — follows you if the forest still trusts you, wanders off if it doesn't.
- **Restore mechanics** — a vine bridge grown from a planted seed, a spring un-buried so the stream flows again, ancient standing stones that only glow after the spring returns — chain into a small journey.
- **The Heartseed** at the centre of the forest offers one final choice: **Take**, **Leave**, or **Share**. The ending you receive is a function of how you played the whole run plus that final choice — not a switch, a scale.

Three endings: **The Guardian**, **The Balance**, **The Silence**.

## Technology

Everything ships as static files. Runtime is 100% client-side.

| Component | Version | License |
| --- | --- | --- |
| React | 19.0.x | MIT |
| ReactDOM | 19.0.x | MIT |
| Three.js | 0.161.0 | MIT |
| WebAudio API | (browser) | Web standard |
| HTML5 / WebGL2 | (browser) | Web standard |
| Craco (build) | dev-only | Apache-2.0 |
| Tailwind CSS + PostCSS (dev-only) | dev-only | MIT |

**Only these three libraries** — React, ReactDOM, and Three.js — actually ship in the production bundle. All other packages in `package.json` are development tooling and are not imported at runtime.

- Client-side only; works offline after first load.
- Saves via `localStorage` (three keys — `wnl_save_v1`, `wnl_settings_v1`, `wnl_endings_seen`).
- No backend calls. The FastAPI template in `/app/backend` is untouched and unused by the game.

## AI disclosure (jam-required)

- Built with the **Emergent AI agent platform** using **Claude** for development assistance and code generation across all phases.
- **ALL** 3D geometry, textures, animations, and audio are procedurally generated at runtime by code written for this project:
  - Meshes are built from Three.js primitives (BoxGeometry, CylinderGeometry, SphereGeometry, custom BufferGeometry, InstancedMesh for vegetation).
  - The heroine's facial texture is painted onto a CanvasTexture at runtime (no image files).
  - All animations (walk, run, jump squash, ponytail physics, procedural facing) are hand-driven skeletal-like transforms — no `.gltf`, `.fbx`, or animation files.
  - The full audio bed (wind, insects, water, rain, birds, footsteps, music, SFX) is synthesised by `AudioEngine.js` at runtime using OscillatorNode, AudioBufferSourceNode (with in-memory white/brown noise buffers), BiquadFilter, and Gain nodes. **No `.mp3`, `.wav`, `.ogg`, or any audio file is shipped or fetched.**
  - The explorer's-journal map is drawn programmatically to a `CanvasRenderingContext2D` at 1080×720 (parchment grain via random rectangles + inky organic blob paths).
- No third-party audio or art assets of any kind ship with the build.

### Fonts

The game uses **only system fonts**. Text renders through the standard CSS `serif` / `italic serif` fallback chain and the browser's default UI stack. No `@font-face`, no Google Fonts request, no font files bundled. On modern desktop OSes this typically resolves to Georgia / Iowan Old Style / DejaVu Serif — all system-provided.

Two decorative faces are *listed* as preferred choices in the map canvas font stack (`"Cormorant Garamond"`, `"Iowan Old Style"`) but neither is loaded — the browser falls straight through to system serif when they aren't installed. This keeps the build under 250 KB gzipped.

## How to run

### Play the hosted build
Open the URL provided with the jam submission in a recent desktop browser (Chrome / Edge / Firefox). Click **Click to Play** or **Continue**. That's the whole install step.

### Build & run locally
```bash
cd frontend
yarn install
yarn build              # → frontend/build/
# Serve the static folder with anything — for example:
npx serve -s build      # then open http://localhost:3000
# or with Python:
python3 -m http.server 3000 --directory build
```

Nothing else is required. There is no `.env` file to configure, no backend to start.

### Development server
```bash
cd frontend
yarn install
yarn start              # opens http://localhost:3000 with hot reload
```

## System requirements

- **Desktop** browser only — the game requires a keyboard, a mouse, and Pointer Lock support. Not designed for phones or tablets.
- Recent **Chrome, Edge, or Firefox** (any browser with **WebGL2** and the **WebAudio API**).
- **Hardware-accelerated WebGL2** — check `chrome://gpu` if the game runs slowly.
- Roughly mid-range integrated GPU or better recommended for the **High** graphics preset. If your framerate stays below 30 FPS for ~5 seconds the game will automatically step the preset down (High → Medium → Low) once and show a quiet notice; you can also pick a lower preset manually from **Settings → Graphics**.

---

## Known limitations

- **Desktop only.** No touch controls, no mobile layout, no gamepad. Pointer Lock is required for the mouse-look camera.
- **Pointer lock quirks.** Certain browsers rate-limit re-locking pointer after Esc — the pause menu handles this cleanly, but repeated Esc-mash may briefly wait a beat before letting you re-lock.
- **Single-slot save.** One save per browser, cleared automatically after any ending is reached.
- **Save fast-forwards, doesn't re-play.** Continuing a saved run re-applies flags visually (vine bridge grown, stream flowing, stones glowing, heart gate open) but does not re-play the cinematics you already saw.
- **Auto-degrade is one-shot.** The performance watcher will lower Quality once per session; if you then set it back to High manually the watcher won't step it down a second time.
- **No audio if the browser blocks autoplay.** AudioContext is created on your first menu button click. If you Continue without ever clicking a menu button first (impossible in normal play — Continue is a menu button) the game will still work but be silent until you interact with a UI element.
